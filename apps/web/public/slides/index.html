Motivación

Un documento revisado por IA es imposible de distinguir de uno falso

Hoy, verificar que una evaluación es auténtica obliga a confiar en la plataforma que la emitió. Si esa plataforma desaparece o miente, la prueba se cae.

Sin solución
  • Un PDF revisado por IA es indistinguible de uno manipulado
  • No hay forma de comprobar de manera independiente la integridad de una evaluación
  • Toda verificación exige confiar en la plataforma emisora
Con Ancrux
  • Huella canónica del registro anclada en blockchain (inalterable)
  • Verificación pública sin confiar en Ancrux
  • Cualquiera recalcula la huella y la compara por sí mismo
¿Por qué blockchain? El estado de la cadena es auditable por cualquiera y no depende de Ancrux para existir — ni siquiera para sobrevivir.
El concepto

¿Qué es un Registro Digital de Confianza?

Un DTR (Registro Digital de Confianza) es la partida de nacimiento de tu documento: prueba qué se certificó, cuándo y que no cambió ni un carácter desde entonces.

Cómo funciona por dentro

De un archivo a una prueba pública

Cuatro capas independientes. Cada una hace una sola cosa y deja una evidencia que la siguiente no puede falsear.

Ninguna capa necesita tu confianza: el resultado se comprueba de forma matemática, no por reputación.

1 · Documento
El usuario sube el archivo de forma privada.
2 · Análisis con IA
Detecta tipo, idioma y genera un resumen de contexto.
3 · Huella SHA-256
Se calcula la huella única del archivo, byte a byte.
4 · Anclaje en blockchain
La huella queda pública e inalterable en Base. Verificable para siempre.
Paquete central

dtr-core

TypeScript puro — sin framework, sin base de datos, sin IA. La única fuente de verdad del protocolo DTR, reproducible en cualquier lenguaje.

canonicalize(value)

Serialización determinista (RFC 8785): claves ordenadas, números normalizados, campos nulos excluidos. El mismo DTR produce la misma cadena en cualquier entorno.

computeCanonicalHash(record)

SHA-256 sobre la forma canónica → hex de 64 caracteres. Idempotente: mismo DTR, mismo hash, siempre.

verifyAssetAgainstRecord(record, sha256)

Valida el DTR y compara la huella del archivo. Devuelve asset_verified · asset_mismatch · invalid_record.

Blockchain

AnchorRegistry · el contrato mínimo

Sin owner, sin lógica de negocio, sin sorpresas. La menor superficie de ataque posible.

anchor(bytes32 hash)

Ancla la huella en la cadena y emite Anchored(hash, sender, timestamp). Revierte con AlreadyAnchored si ya existe o ZeroHash si es cero.

isAnchored(bytes32) → bool

Consulta pública, gratuita y sin permisos. anchoredAt(bytes32) devuelve además el timestamp del bloque.

  • Sin ownership ni control de acceso
  • Chain id 84532 · Base Sepolia
  • Probado con Foundry (unit + fuzz)
  • Desplegado en 0xe6738f…607C22
ADR-003: se descartó ERC-721 por overhead innecesario para el MVP.
Solidity ^0.8.20
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract AnchorRegistry {
    event Anchored(bytes32 indexed hash, address indexed sender, uint256 timestamp);
    error AlreadyAnchored(bytes32 hash);
    error ZeroHash();

    mapping(bytes32 => uint256) public anchoredAt;

    function anchor(bytes32 hash) external {
        if (hash == bytes32(0)) revert ZeroHash();
        if (anchoredAt[hash] != 0) revert AlreadyAnchored(hash);
        anchoredAt[hash] = block.timestamp;
        emit Anchored(hash, msg.sender, block.timestamp);
    }

    function isAnchored(bytes32 hash)
        external view returns (bool)
    {
        return anchoredAt[hash] != 0;
    }
}

Cierre

Conclusiones

IA + blockchain resuelven el problema de la confianza sin exigir que quien verifica confíe en quien emite.

La arquitectura hexagonal permitió desarrollar y probar el dominio aislado por completo de la infraestructura, sin acoplarlo a ningún framework ni servicio externo.

dtr-core como paquete puro garantiza que la canonicalización y la verificación sean reproducibles por cualquier implementación futura, en cualquier lenguaje.

El MVP está en producción, con flujo completo probado end-to-end contra Base Sepolia real y 534 pruebas automáticas pasando en CI.
